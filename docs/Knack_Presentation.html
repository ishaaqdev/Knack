ModuleWhat it doesWhy it is built that way
authPasswords, sessions, guards Only the hash of a session token is stored — a leaked database gives nobody a way in

Results · measured

A problem we found, and how we fixed it

Almost every scenario opened the same way. Telling the AI to “be more varied” changed the words, not the shape.
Before

Two pairs were word-for-word identical.

After

Zero duplicates. Six different people to face.

We stopped asking the AI to be varied — and generated the variety ourselves.

Challenges

Seven things broke. Here is what we learned.

Every one was found by watching the running system, not predicted on paper.
What brokeWhyWhat we changed
Free AI quota gone in hours 50 free requests a day. Our own retries burned 6 per scenario. One try per model. Never retry a rate limit.
The backup model failed too Both models came from the same provider. Rebuilt across three separate providers.
Every scenario looked alike Asking the AI to vary changed words, not structure. We sample 18,480 shapes and require one.
Stuck on one project The GitHub summary named a project and the AI fixated. Show the summary, send only the tech list.
It read the profile aloud “As a final-year CSE student aiming for…” Background sets the scene, never appears in it.
Some models returned nothing They wrote their reasoning first and ran out of room. Turn reasoning off, raise the limit.
Another app stole our port We only worked at all because of an IPv6 accident. Moved port, bound loopback explicitly.

Current progress

Where the project stands today

Working and demonstrable
  • Accounts, sessions, protected routes
  • Onboarding — one question per screen
  • Three tracks, AI generation and grading
  • GitHub grounding, memory that carries forward
  • Adaptive difficulty, XP, levels, streaks
  • Full history with replay
  • Offline mode, clearly labelled
  • Responsive on phone and desktop
What we cannot claim yet
  • One grader, unchecked. We showed it separates good from bad — not that it agrees with a human expert.
  • Made-up students. Tested with profiles we wrote, not a real class.
  • No learning study. The machinery works. Whether it makes anyone better is unproven.
